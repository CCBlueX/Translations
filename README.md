# Translations

Translations of LiquidBounce and LiquidLauncher, served at https://i18n.liquidbounce.net so the clients get fixes and new languages without an update.

This repository is filled by the projects, the way LiquidBounce fills [LiquidBounce-Theme](https://github.com/CCBlueX/LiquidBounce-Theme). Translate in the projects themselves:

- LiquidBounce: [`src/main/resources/resources/liquidbounce/lang`](https://github.com/CCBlueX/LiquidBounce/tree/main/src/main/resources/resources/liquidbounce/lang)
- LiquidLauncher: [`src/locales`](https://github.com/CCBlueX/LiquidLauncher/tree/main/src/locales)

Every change there syncs `next/` with the project's default branch and `<version>/` with its latest release. A release keeps its own wording and takes newer translations only for strings whose English has not changed since. Older releases stay as they were.
